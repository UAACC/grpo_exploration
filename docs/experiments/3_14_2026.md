  ---
  分析

  1. Online GRPO 是唯一在两个任务上都提升的方法

  排序清晰：Online > Mixture B > Mixture A > Offline > Baseline（GSM8K），Online > Baseline > Mixture A > Mixture B > Offline（MATH）。

  核心原因：on-policy vs off-policy。Online GRPO 的 rollout 来自当前 policy，IS ratio 天然在 1.0 附近，梯度信号强。

  2. 为什么 MATH 上所有 offline 方法都低于 baseline？

  模型太弱 + 任务太难 = 学习信号崩溃

  训练 log 提供了直接证据：

  frac_reward_zero_std: 0.63 → 0.73  (epoch 0 → 5.5)

  这意味着 63-73% 的 prompt 组中 5 个 rollout 的 reward 完全相同（全错或全对）。对这些 group，GRPO advantage = 0，没有任何梯度信号。只有 27-37% 的 prompt 提供有效学习。

  对比 GSM8K：baseline 47.79%，student 有大量 mixed 组（部分对部分错），advantage 信号丰富。MATH 上 baseline 只有 30.36%，大部分题全错。

  3. 你之前的两个假设都成立

  H1（advantage collapse）：已证实。 frac_reward_zero_std = 0.65-0.73 说明 Method B 中大部分 teacher advantage 会被 collapse 到 0（因为 student mean reward 就是 0 或 1）。

  H2（IS ratio clipping）：间接证实。 0.5B student 和 7B teacher 的 policy 差距极大。当 π_student/π_teacher 远离 1.0 时，PPO clip [0.8, 1.2] 把梯度截断为 0。这在 MATH 上更严重，因为 teacher 生成的长推理链（avg ~580
  tokens）中每个 token 的 logprob 差异都在累积。

  4. 一个有意思的发现：cross-dataset transfer

  从 eval-all 数据：
  - Offline GRPO trained on GSM8K → eval on MATH: 30.52%
  - Offline GRPO trained on MATH → eval on MATH: 27.64%

  在 MATH 上训练反而比在 GSM8K 上训练更差！这说明 MATH 上的 offline 训练在主动损害模型——因为强行把 student 推向它根本无法产生的 teacher 风格 completion，破坏了已有的推理能力。

  5. 根本原因总结

  └──────────────────────────┴───────────────────────┴──────────────────────────┘

  结论：offline/mixture 方法有一个隐含前提——student 需要在目标任务上有足够的初始能力（~45%+ accuracy）才能产生有意义的 reward variation。 当 student 太弱时（MATH 30%），advantage 信号崩溃，offline signal 反而有害。

  6. 下一步建议

  1. 验证 H2 的定量证据：跑 diagnose_method_B.py，直接测量 IS ratio 分布和 clip fraction
  2. 尝试在更强的 base model 上跑 mixture：如果用 7B student，MATH 上的 frac_reward_zero_std 应该大幅降低
  3. Online GRPO on MATH 跑更多 epoch 或调参：目前 +1.7% 提升不大，可能还有空间（lr, beta, num_generations）
  4. 研究 advantage 计算方式：当 std=0 时，不一定要给 0 advantage——可以用全局 baseline 替代 group-level baseline
